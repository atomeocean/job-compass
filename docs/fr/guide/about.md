# À propos de Job Compass

Job Compass est une bibliothèque gratuite et open source de retours d’entretiens du marché de l’emploi américain. Chaque retour suit la même structure (entreprise, poste, niveau, étapes d’entretien et résultat) et s’accompagne de profils d’entreprises, d’offres d’emploi et de guides de carrière.

::: info Version française
La version française en est à ses débuts. Nous traduisons les contenus petit à petit ; les contributions sont les bienvenues.
:::

## Qui le conçoit

Job Compass est conçu et maintenu par l’équipe d’Atomeocean, avec les contributions de la communauté. Atomeocean est une entreprise technologique américaine fondée en 2021 et basée à New York.

- [À propos d’Atomeocean](https://logbook.atomeocean.com/en/about-us/)

## Contribuer

Toutes les modifications sont proposées sous forme de pull requests sur le [dépôt GitHub public](https://github.com/atomeocean/job-compass). Un mainteneur relit et approuve chaque pull request avant sa fusion.
