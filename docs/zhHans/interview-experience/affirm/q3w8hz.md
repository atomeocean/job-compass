# Affirm New Grad Frontend Engineer HR + coding + HM面试经验

<InterviewDetail />

## 面试详情

- **团队**：前端组，组招

理论上有五轮，hr+coding+hm+coding+hm，进行到第一次hm的时候被通知挂了，不清楚之后的流程具体如何

### 第一轮：HR

15分钟不开摄像头，自我介绍，why affirm，why frontend，react熟练度，介绍项目，career goal，最后介绍接下来面试流程，然后告知只有一个hc是组招

### 第二轮：Coding

1小时，白男面试官人很好，题目不是leetcode，更像实际项目，用ts/js完成若干feature，前后端都需要写，最后跑一下网页预览就行

### 第三轮：HM

烙印，理论上30分钟，结果迟到10分钟，晚结束快20分钟，差点没赶上末班车。问了一个实习项目，问了些impl细节，一些常规bq例如challenge/feedback/collaboration，以及对ai的看法。面到一半就觉得vibe不是我喜欢的，我讲bq的时候也不听，像个读bq问题的机器，差点跟他说就这样吧不面了……

## 面试结果反馈

第一次 hm 后被拒，面完一周没动静，问了hr秒回说被拒了
