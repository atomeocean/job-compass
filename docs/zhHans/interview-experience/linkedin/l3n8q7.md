# LinkedIn SWE IC2 面试经验

<InterviewDetail />

## 面试基本信息

- 公司信息：[LinkedIn](https://careers.linkedin.com/)
- 面试时间：2026年9月

## 面试过程

### Elimination Round

初筛主要是基础数据结构与算法，题目包括 Maximum Depth of Binary Tree 和 Zigzag Level Order Traversal。

### DSA Round

正式算法轮包含两类题目：

- Max Points on a Line / Max Collinear Points
- Minimum Length Substring

除了完成实现，也需要处理复杂度和边界情况。

### AI + Coding Round

这一轮要求实现带计数功能的 LRU Cache。

实现完成后，会根据不同 workload 分析 cache hit / miss ratio，并解释不同访问模式对缓存表现的影响。

这一轮不仅考察数据结构实现，也要求能够从系统行为角度分析代码。

### Hiring Manager Round

Hiring Manager 主要围绕过去的项目和工作经历展开，包括项目职责、技术选择和实际工作经验。

### System Design Round

系统设计题目是 Design Google Calendar。

主要讨论系统整体架构、核心组件、scalability，以及不同设计方案之间的 trade-off。

### Technical Communication Round

最后一轮是过去项目的 technical deep dive。

重点包括技术决策、项目中遇到的挑战，以及不同实现方案之间的取舍。

## 总结

这套流程除了传统 DSA 和 System Design，还加入了 AI + Coding 和 Technical Communication，对 coding、系统思维以及项目表达能力都有要求。
