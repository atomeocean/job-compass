# LinkedIn Software Engineer Onsite面试经验

<InterviewDetail />

## 基本信息

- **岗位**：Software Engineer
- **面试形式**：Onsite（VO 5轮）
- **申请渠道**：内推
- **候选人背景**：硕士，在职跳槽
- **面试结果**：Fail

## 面试详情

VO 5轮

### 第一轮：AI Coding

第一轮是AI coding轮，两位三哥，一位面试，一位shadow查看你的代码。考的LRU以及后面的enhancement，比如带ttl，多线程安全等。这轮过了。

### 第二轮：Coding

第二轮手撕算法，国人，两个有序数组，它们两两组合的乘积中返回最小k个。先让我用暴力解，然后用优先队列优化。莫名其妙挂了。

### 第三轮：Hiring Manager

第三轮host manager面，BQ+简历，还是三哥，过了。

### 第四轮：System Design

第四轮SD，设计一个error message计数器，国人，挂了。

### 第五轮：Technical Communication

第五轮technical communication，其实还是挖简历，貌似是中东的哥们，过了。

## 面试体验

我现在的问题已经从怎么通过面试变成了怎么清理掉这些恶心人的国人了。

## 面试结果反馈

- **最终结果**：Fail
