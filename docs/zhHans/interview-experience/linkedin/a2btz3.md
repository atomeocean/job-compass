# LinkedIn Software Engineer Onsite面试经验

<InterviewDetail />

## 面试详情

- **面试形式：** Onsite
- **面试语言：** Senior App Track

### 第一轮：Coding

lc 44，272

### 第二轮：SD

Post Search。Deep dive主要集中在怎么快速判断key word在哪些post？Exclude key word要怎么实现（比如说post里要有apple但不能有banana）？返回post result的时候要怎么根据key word的频率返回？

### 第三轮：AI Coding

过山车安排乘客的问题，给你每一排有几个座位、一共有几排、每运行一次过山车花多久时间、两次运行间隔上下乘客花多少时间。告诉你等待乘客每一组有几个人，一共有几组和每组乘客必须满足某种条件的乘坐规则(规则部分有一点忘了)。求一共要几趟？总耗时多少？座位的利用率之类的？我不记得所有细节，总之题目非常长！9月中面试的时候可以用Codex 5.x，没有遇到旧一点的面经说的AI很难用的情况，可以斟酌选择AI的thinking level，我是偏向选中低，等的没那么久，可以多iterate几次。面试一开始也有跟面试官align好AI的使用程度，面试官说随意使用，只要Code最后能跑通测试就行，就当作自己在工作中遇到这个问题。

中规中矩

## 面试结果反馈

- **最终结果：** Fail
- **面试时间：** 9月中
