# Scale AI SWE 面试经验

## 面试基本信息

- 公司信息：[Scale AI](https://scale.com)
- 面试时间：2026年7-9月

<InterviewDetail />

## 面试过程

### Recruiter Screen

周一（2026年7月）与 Scale AI recruiter 进行了30分钟电话沟通，总体难度不高。建议提前用 STAR 模板准备好 **Self-intro**（需要提到 why interested in Scale AI as a company）以及 **Hardest / most exciting project** 相关内容。Recruiter 提到，如果投递了多个岗位，后续会根据简历匹配到最接近的 team 来安排面试。

Recruiter 介绍了后续流程，共有以下两轮：

### Technical Round（待进行）

时长约1小时，recruiter 表示会考察 non-LeetCode style 的题目。根据地里近期讨论推断，可能与近期出现的 task scheduler 相关题目有关。

### Onsite / Virtual Onsite（待进行）

共5轮，预计包含不同类型的 Behavioral Question（BQ）、system design，以及 technical 相关内容。

## 结果反馈

目前仅完成了 Recruiter Screen 环节，结果为 **Pass**（顺利进入下一轮）。需要说明的是：这只是面试流程第一轮的结果，并非最终 offer 结果 — Technical Round 与 Onsite/VO 尚未进行，最终结果仍待定。
