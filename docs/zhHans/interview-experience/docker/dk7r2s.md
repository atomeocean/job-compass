# Docker Senior Software Engineer Recruiter Screen面试经验

<InterviewDetail />

## 面试详情

**时间线**：

10月30日收到 recruiter 邮件，问是否对 Senior Software Engineer, AI Developer Tools 感兴趣

11 月 5 日 Recruiter Screen 电话，约 30 分钟，对方是 Senior Recruiter，电话当场通过

**电话里聊到的细节**：

1. 开场 recruiter 就问我是否认识他们的一位 SVP，我实话实说不认识。电话之后我去 LinkedIn 查，确实有这位 SVP，但我发出的连接请求至今还是 Pending，我也不清楚简历是如何到 recruiter 手里的。猜测我Linkedin加了那位SVP之后，对方看了我的简历，帮忙推荐了。真是填上掉下来个好机会，感谢！

2. 岗位 Fully Remote。

3. **Package**：他先问我的期望，我反问后他直接给了 range：Base ，Equity ，Sign-on 。以 Senior 级别来看算不错的，谈薪环节比较坦诚，不藏着掖着。

4. **完整流程**：Stage 1 = Hiring Manager 面（project + BQ）+ Coding 面（LeetCode 风格）；通过后约 Stage 2 = System Design + Project Presentation，一般安排在相近的两天面完；全部结束后 1–2 周内给反馈。

5. **评级机制（recruiter 原话）**：全员 Yes，一般就会给 Offer；有 Strong Yes，会努力给更好的 package 争取候选人；不需要全员 Strong Yes。

6. **他给的准备建议**：这是 Senior 岗位，BQ 讲 project 时 scope 一定要足够大，能听出来是单人小项目还是跨组高影响项目；Stage 2 的细节等 Stage 1 通过后再约时间单独介绍。

## 面试体验

**个人感受**：整个沟通过程透明度很高，流程、评级、package 都在第一通电话讲清楚，对这家公司印象不错。后续面完 Stage 1 再来更新。另有一个感慨：准备得再多不如尽早投递，面试机会才是真正的推进。
