# Walmart Software Engineer Onsite面试经验

<InterviewDetail />

## 面试详情

大超市的原组 manager refer 到隔壁组（原组没 HC 了），直接约了周中 onsite 面试。当时我在外地，买了张死贵的票赶紧回来了。

3 轮面试

### 第一轮：Manager 面

第一轮是隔壁组的 manager 问的，问我对于 org 内 system 的一些看法，以及一些解决难题的工作经验。例如 你工作中解决过什么技术上的难题吗/有没有与同事有conflict如何解决conflict

### 第二轮：Coding

第二轮是一道题：从第 n 个节点开始合并两个 linked list。给你两个节点，从 nth node开始接入第二条linked list，再从yth node接到第二条linked list尾部

### 第三轮：Coding

第三轮是两道题：第一道是合并区间（merging interval）两个list 里是 start time 和 end time，如果end time 比start time早就要合并掉区间，最后输出没有重复的区间合集。第二道是判断是不是 palindrome string，给你一个string 你需要判断掉有没有 符号和空格，2 pointer解决

## 面试体验

Code 题目都答得不错，第一轮在分配 partition 和 consumer 那里卡了壳。

面试完托人问了反馈也不错，结果隔了两周收到拒信。这真的算是很好的机会了，太可惜了,算是目前第一个走完loop被拒的公司，而且我觉得我buff叠的挺满的(我是面这个组的下游&我们组mgr直接找他refer的&有身份&公司最近猛招人)
