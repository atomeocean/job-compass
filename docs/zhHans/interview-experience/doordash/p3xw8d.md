# DoorDash Data Analyst Onsite面试经验

<InterviewDetail />

## 面试详情

- **团队**：store组

### 第一轮：HR Call

**1st round**: HR call

### 第二轮：Tech SQL + Case

和 DS 的题应该是一样的，我抽到了 bike 的题，考察ab testing流程。

### Final Round

Final round共三轮

#### 第一轮：HM interview

主要也偏向 case，给了一个 specific feature，让你分析怎么 define metrics and build a dashboard for different stakeholders。

#### 第二轮：database design

第二轮比较 confusing，是组里一个 DA 来面 database design。实际上更多是讨论 feature definition，题量很大，没说完，最后没来得及 review SQL，估计挂在这了。

#### 第三轮：BQ

第三轮 BQ with VP，问了一些过往经历、AI usage、怎么分析 metric decrease、conflicts 等等，比较基础。

## 面试体验

感觉DD不咋招DA， 这个岗位是store组下面的，所以面试的题都非常specific，围绕他们的新feature在问，不同组final round很可能是不一样的
