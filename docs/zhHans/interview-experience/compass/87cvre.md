# Compass Software Engineer VO 行为面经验

<InterviewDetail />

## 面试过程

Compass家的行为面有两个，一个是经典的behavioral round， 另一个他们叫technical deep dive，实际上面的内容也大部分是BQ相关领域。Compass的面试准备包里有发company values的pdf，回答的时候记得适当融入。

Behavioral round 基本上和其他公司的流程差不多，面试官抛出一个问题然后自己给例子回答，按照经典的STAR流程走就可以了。
我面的时候面试官问了biggest failure以及argue with manager两个问题，后续追问也都是相关话题，整体没什么坑。

Technical Deep Dive那一轮首先问了一下过去工作经历和公司结构，然后让我挑选了一个most pround project详细解释。面试官问的问题更像是包含一些技术细节的BQ，比如谁主导了这个系统设计，如何决定database schema，内部测试和用户测试是如何进行的。
整体氛围像是给面试官复盘整个project的开发流程，而不是追问某个具体的技术细节八股文。
