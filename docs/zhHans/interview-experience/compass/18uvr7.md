# Compass SDE VO 系统设计面

<InterviewDetail />

## 面试过程

一开始面试官给的题目是design一个data storage system, 要求high throughput，支持大批量读写。

结果等我list完requirements，开始进行design的时候，面试官开始主导方向，问了很多design Youtube相关类型的细节问题，比如global CDN, multipart upload/storage, regional rank lists cache。

我猜测面试官一开始就是奔着design Youtube的题去的，但我理解成了google drive那种文件系统，导致预期design和整体框架差距很大。最后我也不知道往哪个方向走，变成了面试官主导提问某种design pattern，然后我回答实现细节的Q&A形式。

面试官是东欧白人女，口音也是抑扬顿挫，整个面试节奏十分诡异，是我面过的最奇葩的一场system design。

## 面试结果反馈

- **最终结果**：Rejected
