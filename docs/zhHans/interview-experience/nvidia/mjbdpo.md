# Nvidia Software Engineer Onsite面试经验

<InterviewDetail />

## 面试详情

### 第一轮：店面 Coding

第一轮是 1 个店面 coding。

### 第二轮：店面 Coding

第二轮是 2 个店面 coding，还遇到一点难。

### 第三轮：System Design + Bar Raiser

第三轮是 3 个 SD，一轮 bar raiser。SD 都是 infra 类的：KV store、scheduler、分布式软件版本管理器。

bar raiser 其实还挺 nice，问了很多奇怪的问题，感觉是给过了。

### 第四轮：Onsite

然后过了两天，通知要第四轮，现场。给订了第二天的机票，直接给干到湾区来了。说好 1 轮见 M3，结果直接给了 3 轮，每轮 45 分钟。

#### 第一轮：M1 HM

刚从亚麻过来的，全程纯 BQ：项目 trade-off、most challenge、别人给你的最差的意见、你犯过的错误、和同事的冲突、和老板的冲突。前面还行，后面有几个问题有点被节奏打乱了，感觉不太好。

#### 第二轮：senior

第二轮是一个组里的 senior，项目 deep dive。我说得快了一点，他就说听不懂。解释了一下，他好像有明白了。

#### M3

聊了半小时，告诉我说，我是 top 5，他们要招 2 个人，感觉有点试探我是否接受被 downgrade……

## 面试体验

真的是太难了，感觉现在 HM 们都挑花眼了。爱咋滴咋滴吧

## 面试结果反馈

让我等下周通知，说下面还有其他的面试，就走了。
