## 面试过程

Robinhood SDE 岗位VO轮，一共三场面试， system design + coding + project deep dive

project deep dive 那场就是自己介绍一个做过的最厉害的项目，要求做两页ppt展示，面试官深挖技术细节、技术实现的取舍、实际遇到的问题等等，考核的内容类似传统的BQ + technical round 二合一。

system design 考了 job scheduler, 经典题目了，整体没什么特别tricky的问题。地里和 hello interview都有很多学习资料，对着过一遍就问题不大。

coding round 和电面一样也是考了他们自家的题库。大概内容是给一个stock orders 的 list（buy and sell), 需要update account info（balance/stock qty）。里面涉及一些特殊股票类型和交易特殊规则具体的不太记得了，没什么算法难度，主要是data operation的各种小细节。
我自己写的时候用了float type，面试官最后follow-up的时候问到float有什么隐患，还有多线程concurrent怎么保护，dirty data怎么处理，感觉这道题和他们的实际业务比较贴近所以挖的特别深。后来自己复盘的时候才学习到了这种类型的数据最好用Decimal type,之前也是从来没接触过。
