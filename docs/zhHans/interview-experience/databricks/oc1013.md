# Databricks SWE Intern 技术面试经验

## 基本信息

- **岗位**：Software Engineer Intern
- **面试地点**：Amsterdam
- **面试形式**：Technical Interview
- **面试难度**：Average
- **整体体验**：Positive
- **最终结果**：No Offer

## 面试流程概览

本次技术面主要包含两部分：

1. LeetCode 算法题
2. General Coding / OOP 编程题

候选人整体认为面试体验不错，但强调 Databricks 对 Coding 熟练度要求比较高，需要对 LeetCode 保持足够熟悉。

## 第一部分：LeetCode 算法题

第一部分是一道标准的 LeetCode 风格算法题。

原帖没有透露具体题目，但候选人特别提到，面试 Databricks 和其他技术公司一样，需要对 LeetCode 非常熟练，并且有足够的 Coding 信心。

这一部分主要考察：

- 算法与数据结构基础
- Coding 熟练度
- 对常见 LeetCode 题型的掌握
- 能否快速写出正确实现

从候选人的反馈来看，题目本身并没有被评价为特别困难，但需要较高的 Coding 熟练度。

## 第二部分：General Coding / OOP

第二部分不是传统的 LeetCode 算法题，而是一道更偏实际编程能力的 General Coding Question。

### 题目形式

面试官提供一个 Class Definition，要求候选人根据已有的代码结构完成实现。

主要包括：

- 根据已有结构补充 Class
- 实现缺失的方法或逻辑
- 确保整个 Class 可以正常运行
- 根据题目要求完成对应功能

相比第一部分，这一部分更加偏向：

- Object-Oriented Programming（OOP）
- Class Design
- 实际 Coding 能力
- 阅读已有代码
- 根据 Requirements 完成实现

这类题目不只是考察算法，更关注候选人能否在已有代码结构中快速理解需求，并完成一个可以正常运行的实现。

## 面试整体体验

候选人认为整个面试过程总体不错。

面试难度被评价为 **Average**，整体体验为 **Positive**。

不过，即使题目并不属于特别困难的类型，想要顺利完成仍然需要对 LeetCode 和实际 Coding 保持较高熟练度。

## 面试结果反馈

- **最终结果**：No Offer
- **面试体验**：Positive
- **面试难度**：Average

虽然最终没有拿到 Offer，但候选人对整个面试流程的评价仍然比较正面。

## 总结与反思

这次 Databricks SWE Intern 技术面可以分成两个比较明显的考察方向：

### 算法能力

通过 LeetCode 风格问题测试：

- 数据结构
- 算法基础
- Coding 熟练度
- 问题解决能力

### 工程能力

通过 Class Definition / OOP 问题测试：

- OOP / Class Design
- 根据已有 Interface 补充实现
- 阅读和修改已有代码
- 完整代码实现能力
- Debug 能力

因此准备 Databricks SWE Intern 时，不能只刷 LeetCode。

除了常见算法题之外，也建议练习 OOP、Class Design，以及根据已有代码框架实现完整功能的题型。

整体来说，这是一套同时考察 **DSA + Practical Coding / OOP** 的技术面试。
