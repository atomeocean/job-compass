# MongoDB Software Engineer Onsite面试经验

<InterviewDetail />

## 面试详情

- **团队**：Atlas Growth

目前公司真的呆不住了，想尽快跳槽。

忽略Recruiter call，面的Atlas Growth，明确要求TypeScript/JavaScript

一轮Phone Screen，三轮VO，一轮HM

### Phone Screen

字符串相关，设计一个lib可以实现类似JS string Interpolation的function。难度适中主要是讨论一些edge cases如何处理：面试官想让我们决定是throw error还是有别的设计

### VO

#### 第一轮: Code Review 

一段TS code 大概200来行，要求以comment的形式写review，不要求改动。主要是一些常见的undefined/null 的判断，Interface的定义，以及按照design doc去找code里面business logic的bug，test cases是否合理。难度适中，这轮positive feedback

#### 第二轮：Coding

要求手搓一个class 实现Promise的功能，只能用JavaScript，由于好久没手搓JS了刚开始语法上就出现了问题搞得我节奏大乱，最后没完全写完then，收到了mix feedback

#### 第三轮 Backend Design 

这轮不是System Design，主要focus在设计一个类似Google Drive的backend，focus在business logic和DB scheme design上，收到了positive feedback

### HM

这轮就是简历深挖 + BQ，HM会问的特别细，自己在某些问题上表述的有点乱最后收到mix feedback。最终结果就挂了

## 面试体验

整体体验还好，遇到好几个亚裔面试官包括ABC我觉得都还是很不错的。毕竟很久没准备面试了，最近想提桶跑路，Mongo还是很想去的，无奈水平不够哇。求米求米，想解锁面经！
