# Bloomberg New Grad Software Engineer 面试经验

<InterviewDetail />

## 面试详情

我申请了Bloomberg的软件工程师新毕业生岗位并且收到了offer。选拔流程：我有四轮面试，技术面，编程面，管理层面，和最后的HR面。

### 电话面试
在一轮简短的简历浏览之后，面试官是开心和友好的，他迅速转向了面试的技术部分。

第一个问题不要求任何编程只是简单叫你从一串数字字符中打印出不重复的数字。我建议使用set，然后我们就进入了哈希的细节和哈希表是如何工作的。

下一个问题是关于编程的，所以我必须排序树的子节点，每个节点包含着一个子节点的list。子树也必须被带进去。一开始，我试着用层序遍历。后来意识到伴随着提示我解决了。这个之后，我们进入了下一个问题。

这是一个Weighted Job Scheduling问题

最后几分钟是轮到我问问题，大部分是关于项目。这部分也要准备，要问好问题！

### 第一轮：技术面
通过视频聊天，我见了两个面试官。在Hackerrank深入编程之前，我讨论了我简历里的一个项目/实习。

在那里我被给了一维整数数组，问题是找到最长的子序列长度 https://www.geeksforgeeks.org/dsa/longest-consecutive-subsequence/

第二个问题是把我难住了。问题是基于一个正整数数组。答案包括反复排序并且把元素替换成最小的数，但我遇到了麻烦。在面试官给了我一些提示后我做到了。我害怕我因为这个问题被拒绝。

在最后几分钟，他们问了我关于我的情况。
### 第二轮：技术 coding 面
我又一次通过视频面试遇到了两位面试官。在Hackerrank深入编程之前，我讨论了我简历里的一个项目/实习。

第一个问题是关于Stock Span Problem https://www.geeksforgeeks.org/dsa/the-stock-span-problem/

我被给了一个二叉树并且我要查看它是否完全 https://www.geeksforgeeks.org/dsa/check-if-a-given-binary-tree-is-complete-tree-or-not/

第三个问题很简单，要旋转给定的链表 https://www.geeksforgeeks.org/dsa/rotate-a-linked-list/

### 第三轮：经理面
我见到了一个资深经理并且没有编程说了一个小时。这实际上是一轮设计面，但包括了一些我简历上的东西。我被测试了我的技术知识并且应对的不错。这一轮很顺滑，最后几分钟保留给我的问题。

### 第四轮：HR 面
这一轮比其他的更简短并且进程很快。我到这时候已经很累了，喝了四瓶水并且没有吃任何东西，即便是简单的问题对我来说也耗费一些精力。但一切都很顺利。面试官问的一些问题包括：

为什么我们要雇佣你

你会为我们做什么

这是你最喜欢的公司么？或者告诉我你最想去的最喜欢的公司？

你期待从公司获得什么？

你在被雇佣的时候会改变什么？

这些问题很刁钻我是凭借反应临场作答的。几天之后我收到了公司的邮件。

结果：我在一周内被联系并获得了offer！

## 面试体验
想法：

所有面试官都很赞，并且我很享受。

在面试过程中我们必须保持专注并且对面试官的问题提供合适的回答。

面试之前提前准备的话你就不会在任何地方卡住

## 面试结果反馈

- **最终结果**：通过

## 投稿人的理解与总结

我认为这几轮面试的问题难度不大，总体来说考察的是基本功和对项目的反思，尤其是对于过去的项目是否掌握。在经理面试那一轮尤其考察了项目设计和架构是区分大部分候选人的地方。
