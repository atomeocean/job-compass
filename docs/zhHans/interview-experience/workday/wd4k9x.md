# Workday 技术一面面试经验

<InterviewDetail />

## 面试详情

- **面试平台**：HackerRank

面试形式非常不同。HackerRank 给了一个很大的代码库，前后端都有，后端是用 Express + JS 写的

给了八个失败的 unit test，让我修八个 unit test。每一个都不难吧，就是找到某个条件没写好、某个字段没写对之类的

我只改出了三个。第四个找到问题了，但是不太熟悉语法，所以没做出来。

## 面试体验

其实整体的面试不算难，也很贴近日常生活，但是完全没有准备过这种类型加上也已经很久没有写代码了，所以有点紧张吧

## 面试结果反馈

感觉面试官的反馈也比较一般，估计进不了下一轮了
