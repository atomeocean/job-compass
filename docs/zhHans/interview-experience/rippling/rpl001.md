# Rippling Senior Software Engineer Onsite面试经验

<InterviewDetail />

## 面试详情

十月中收到recruiter reachout 开始流程

### Recruiter call

十月底，问得感觉比一般recruiter call更深，有问最challenging的project，为什么想要换工作，why rippling，工作中如何使用ai，甚至问了目前有什么事情是ai做不到的。这里建议表现得对rippling比较有热情

call完之后没多久十一月初就约了第一轮

### Technical screen

面经在这里： https://www.1point3acres.com/bbs/thread-1195625-1-1.html

第一轮之后一个工作日通知进入onsite轮，换了一个组招的hr来先聊了半小时天，其中还go over了电面轮的feedback，表示虽然电面的三个小问中只有时间写了两小问，最后一问只进行了口头讨论，"but it was good enough for your level (senior)",所以大概staff+会需要所有小问都写出来吧

virtual onsite在11月中旬进行，三轮分了两天：

### Web API AI coding

面我的是一个很nice的abc小姐姐，这一轮和其他面经说的一样，是一个hr系统，要加一个可以schedule change的feature，比如说明年1/1起某人的title变成director之类的。

在开始写之前花了很长时间讨论各种tradeoff，甚至有点system design的感觉？比如data model 如何更改，这些change应该在write time还是read time去apply. 感觉小姐姐那边是有一个checklist，会给hint让你hit到一些点，此处比心🫰真正开始写代码大概只剩20分钟了吧，我先让ai写了个plan出来，review plan之后implement，再加test case，讨论test case是否完整，此处小姐姐继续给hint。

最终完成了backend change就没有时间了，frontend也没改。我本来以为这轮可能挂了因为都没完全写完，但结果recruiter说这轮feedback很好，tradeoff也都讲的很清楚。

### Project deep dive

这轮面我的是一个不苟言笑的欧洲人manager，口音有一丢丢难懂。我准备了大概四页slides来聊我的project，从最一开始的background面试官就疯狂dive deep问问题，第一张background slide讲完大概已经过去一半时间了🥲 后来的overview每个点也都会问"这里为什么选这种技术""这两条arrow如果fail了怎么办"，就和system design里的deep dive差不多吧，这里的learning是图上出现的任何component和箭头都得知道tradeoff和failure recovery。

在讲完high level之后已经没有太多时间了，我deep dive了一个自己own的component，讲了一些细节，这边反而问得不是很多了。最后几分钟问了这个project的quantifiable impact，以及一个behavioral问题"有没有mentor过谁"。

hr说这一轮的project本身没有什么问题，negative feedback主要是觉得presentation focus不够好，花太多时间讲复杂的system overview，tradeoff的discussion不够deep，以及impact没有quantifiable。此处给大家的learning是一定要focus在自己own的东西上，background和overview可以说得abstract一些不需要过多细节，同时要准备好数字/metric展现impact，所有部分的tradeoff也要完全了解，只要是放上slides的部分都需要自圆其说。

### System design

面我的是一个国人大哥，题目是hotel booking system，需要可以ingest hotel info from different sources (hotel api, webhook,crawling), view available hotel given location/dates, book hotel room.

大哥从最一开始就deep dive了，还在讲requirement的时候大哥就让写data model，还讨论了hotel room怎么存比较好 "应该每个room一行还是每个room type一行?"，讨论了tradeoff。 之后的每个component也在一开始就dive deep，聊完read path之后大哥让先聊ingestion，就开始设计那个部分，讨论要不要central coordinator来assign job之类的。

因为一直deep dive最后到booking flow的时候已经没有什么时间了，楼主在准备这道题的时候确实也真的没有准备payment，没想到这个也要考到，这里犯了个错，大哥说"你想想进入Booking page之后应该会怎样" 我说那就应该输信用卡信息，点book button了，大哥说一般会有一个五分钟count down，这我确实没想到count down也要考到。果然hr给的feedback里面说这边是比较大的扣分点，还说觉得整体的flow was left open, 我就excuse me了，面试官每个部分都dive deep没时间把booking flow讲完我能怎么办？in general我感觉大哥那边也有一个checklist需要看你的答案有没有每个点都聊到，这道题其实很复杂，每个flow单拎出来都能讲很多了，所以经验是速度很重要，要能快速主动的把每个地方的得分点讲出来才可以。

## 面试体验

虽然最后面试没有过，但总体面下来体验很好，没有ghost/严重迟到现象，大家都很nice，速度也快。我最喜欢的一点是hr愿意在拒了你之后还花15分钟go through feedback，所以我推荐所有人去申请这个公司，就算没有过也能得到feedback这就吊打很多其他公司了。

我之前用过两次mock interview platform来mock system design，但是得到了conflicting feedback，而且我意识到这些platform上的面试官并没有incentive给你最真实的feedback，就像dating app希望你可以留在app里一样（笑），就显得rippling这样会提供feedback的公司尤其珍贵。同时这个公司题库很小，面经很多，大家在去面试之前都会好好准备，每个面试官都well calibrated，有一套完整的rubric，所以导致bar会比较高。

手动打了这么多字实属不易，求大家加米看面经！祝愿大家面试都面到刷过的题，offer多多！谢谢大家！
