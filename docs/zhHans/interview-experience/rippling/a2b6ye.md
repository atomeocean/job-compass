# Rippling Software Engineer 技术电面面试经验

<InterviewDetail />

## 面试详情

- **面试平台**：HackerRank（使用 hackerrank 自带的 AI）

### 技术电面：AI Coding

国人大哥出了一道经典面经题camel cards。和面经一样，第一问evaluate两个hand哪个大，第二问加best hand和worst hand，楼主（AI）写了暴力解法，最后口头讨论了如何optimize

## 面试体验

之前hr说这一轮可以选择是否使用AI，但是面试官一上来就说是AI coding似乎没有选择？之后要面的朋友们这个最好跟hr/面试官确认一下，还好楼主本来就是准备用AI的。用的是hackerrank自带的AI，面试之前熟悉一下interface还是很有必要的。之前看面经说不能啥都交给ai写，得有自己的想法所以楼主的做法是在代码comment里写自己的想法然后让ai根据comment implement，ai还是很给力的！

## 面试结果反馈

周五面的，周一就收到onsite邀请了，感谢国人大哥，好人一生平安🙏
