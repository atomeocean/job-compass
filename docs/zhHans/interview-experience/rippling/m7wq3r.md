# Rippling Software Engineer 电面与Onsite面试经验

<InterviewDetail />

## 面试详情

来回馈地里，加油大家

### 店面

task scheduler

### Onsite

4轮onsite

#### 第一轮：coding

Logger那道题，这道题主要考的应该是OOD，重点在于你怎么design这个结构然后可以在未来能有效利用。要搜索keywords那里注意一下如果把方法放到存message的那个handler里的话，后面的handler就不能重复利用了，所以应该建一个interface让需要搜索关键词的handler去implement这个interface。

#### 第二轮：系统设计

他家面经出现最频繁的那道题，根据每个用户的订阅和关注给出定制新闻池。我当时是没时间看完网上他家全部的topics，但是发现这个题还有另一个event的题出现的频率比较高于是把其他的topics弃了重点准备了这两个，结果就中了。

#### 第三轮：department screen

20分钟给面试官展示几个slides讲你的项目，他会问你问题。这轮如果面senior+建议一定要选scope最大的项目，我本人就是这轮面的最差，挑了一个0到1的项目但是面试官觉得scope不够大（我猜可能是因为我的项目的用户量太少，他有问多少user在用）。剩下的时间也是跟你聊些bq啥的，我好像有被问到一个被同事或manager challenge的时候。

#### 第四轮

一轮和比较高级别的人闲聊，这轮他主要想知道你的passion啥的，为啥想去他家，建议提前也想好。

## 面试体验

他家总体面试体验比较好，流程很清晰，recruiter一开始就给你讲好了流程，甚至没轮面完还会给你分享feedback。唯一比较烦的就是department screen你要去花时间准备一个presentation。这个花的时间只在他家面试有用，不像SD准备了也可以build up其他家的面试。
