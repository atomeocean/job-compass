# Temu SDE 面试经验

## 面试基本信息

- 公司信息：Temu（拼多多旗下）
- 面试时间：2026年7-9月

<InterviewDetail />

## 背景

候选人离职后，Temu HR 主动联系并推荐了一个 Java developer 岗位（该岗位要求 3 年以上经验）。候选人此前工作使用 C#，此次面试语言切换为 Java 相关技术栈。由于 Temu 很多业务需要和国内团队对接，面试官均为中国人。

## 面试过程

### 一面（Technical Round）

面试官首先深挖简历，询问上一份工作的业务逻辑和技术实现细节（如数据库存储设计、存储内容及原因），主要用于核实项目是否为候选人本人所做。

随后是八股文环节，涉及 MySQL 事务级别、MySQL cluster（候选人表示不了解）、Java 泛型，以及候选人此前工作语言 C# 的垃圾回收机制。这些问题基本围绕候选人过往工作经历展开。

编码题为「完美平方数」的变体（例如 12 可以拆分为 4+4+4），与 LeetCode 原题不同的是要求给出具体是由哪些数相加组成，而非只求个数。

整体节奏偏轻松，面试官态度较好，双方就部分技术细节进行了探讨。面完当天晚上即收到 HR 通过通知。

### 二面（Hiring Manager 面试）

面试官为 order system 负责人。相比一面偏重技术细节，二面面试官更关注系统设计相关内容，并询问了候选人在原公司的绩效情况，问题风格偏向管理层视角。

编码题为数组最大子串个数问题（如 (1,2,3,7,5) 的最大子串个数为 2，1237 和 1235 均为最大子串），需要维护两个 DP 数组。候选人最初只想到需要用 DP，未能想到需维护两个，面试官给出提示后仍未能完整解出。

随后是行为面试问题，包括「你的优缺点是什么，为什么」「你的组长会如何评价你，为什么」等。全程面试时长约 1 小时 50 分钟，候选人自述后半程状态疲惫、行为面回答有些恍惚，一度以为会挂。第二天晚上收到通过进入三面的通知。

### 三面（Final Round）

面试官为 order system 的 tech lead，候选人形容交流氛围非常愉快。流程与前两轮类似，先挖掘简历（重点仍是验证项目真实性），随后进行编码题。

题目为 LeetCode 第三题，候选人较快解出；面试官追加了一个 follow-up（若可重复一次元素应如何处理），候选人也很快给出答案。

面试当晚即收到 HR 后续流程通知，第二天完成 HR 面（形式较为轻松，类似聊天），随后进入谈薪阶段。

## 结果反馈

最终结果为 Pass，三轮技术面试通过后进入谈薪环节。

## 总结

候选人自述整体表现并不算突出（一面部分八股文答不上来，二面 DP 题未解出），但与各轮面试官交流氛围良好。候选人认为 Temu 招聪明速度快，看重与面试官的沟通契合度。
