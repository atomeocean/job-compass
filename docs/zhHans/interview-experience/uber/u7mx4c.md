# Uber 士大夫 店面

<InterviewDetail />

## 面试详情

- **考试平台**：HackerRank

店面的形式是45min coding + 15min Design

### Coding

coding碰到了[find robot高频题](https://www.1point3acres.com/bbs/thread-1187778-1-1.html)。跟面试官讨论了下brute force solution以及如何precompute 四个方向的距离做提速，最后写了优化版本的solution。面试官没有在hacker ranker提供test cases，也没要求我写，仅仅口头dry run了题目自带的case就move on 到design了。

### Design

Design非常free form，uber自己官网guidelines写的是会被问一个之前做过项目的challenge和决策过程，但是面试官直接问了UAIS 从customer下达任务到driver完成任务upload evidence整个e2e flow有什么地方可leverage ml ┓( ´∀` )┏。我从用llm从customer collect leads + 给driver generate followable guideline + 用ML 验收evidence quality三个角度浅答了一下

## 面试结果反馈

- **最终结果**：通过，进入 Onsite
- **体验 / 难度**：Neutral / Average

店面第二天收到了onsite邀请
