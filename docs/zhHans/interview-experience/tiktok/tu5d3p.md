# TikTok USDS 应届 技术电面面试经验

<InterviewDetail />

## 面试详情

- **团队**：USDS

总时长一个小时。

先他自我介绍，再我自我介绍

然后

1. 首先从CV找一个project自己讲讲，然后他follow up

2. 然后coding，平台是hackerrank。题目是[210](https://leetcode.com/problems/course-schedule-ii/)的一个变题，medium难度，用topological sorting做，两个方向都能做。 但反正我一开始卡很久，他一步一步guide的，直接很好心地把topo_sorting贴给我了 。最后也没有test，他看着过了就过了（也可能我浪费时间太多了hh）

3. 最后考ML foundation，这里没有coding环节。问数据极度imbalance情况下使用什么measurement

   提示AUC然后PR_AUC

   confusion matrix里面precision和recall （这里有点绕进去了说半天没说明白，医疗金融和他们risk做假账户关注点不太一样，自己属实发挥稀碎）

## 面试体验

面试官是好人，看我这么菜也是很积极的引导和给hint。

HR也是好人，之前是主动约快速推进（强烈看不起TT主体的几个，LinkedIn乱发小广告，发了邮件也完全不回），下午五点结束，晚上九点我吃着火锅唱着歌拒信就来，也算没有浪费太多时间
