# InterSystems NG Quality Development Program 技术面面试经验

<InterviewDetail />

## 面试详情

想来分享一下这段非常迷惑的经历……

### HR Call

楼主最开始是被 HR 主动 reach out，问对 Quality Development Program (QDP) 有没有兴趣。于是就提交了申请。后来仔细了解了一下发现 QDP 主要是 software quality / QA 方向的，而楼主其实更想做 software development，所以在 HR call 的时候顺便问了一下有没有可能转去 Core Development Program (CDP)。

结果 HR 的回答直接给我整不会了：CDP is very competitive，generally reserved for Ivy League students.

？？？

当时听完真的满头问号。知道 CDP 更 competitive 完全可以理解，但直接说一般是留给 Ivy League 学生的还是第一次听说，感觉就是一个很condescending/不太educated的response……不知道这是 HR 自己的理解还是公司的招聘标准，反正当时听着就挺不舒服的。不过想着既然已经开始流程了，就继续面吧

### 第一轮：Technical Interview

之后约上了第一轮 technical interview。InterSystems 的 tech 面和传统 SWE 面试不太一样，没有什么 LeetCode，问题基本都是比较 high-level 的 technical / behavioral questions，主要考察你的思考方式和解决问题的思路。

### Reference Check

第一轮面完之后收到了 positive feedback，直接进入 reference check。楼主也很配合地提供了 references，推荐人那边也都完成了流程。本来以为都到 reference check 这一步了，应该离最终决定不远了，结果突然被告知管理层决定调整招聘流程，需要额外增加一轮 technical interview。

虽然觉得这个时间点突然改流程有点奇怪，但多面一轮本身也没什么。完全理解，愿意配合安排。

然后就开始等 scheduling email。等了一周多，什么都没有。

于是楼主主动给 HR 发邮件 follow up，问一下第二轮面试的安排。HR 没有回复，但紧接着就收到了 scheduler 发来的约面试邮件。

这里插一句，整个招聘过程中，楼主给 HR 发过好几次 follow-up email，但从头到尾一次都没有收到过 HR 的直接回复。 每次都只能靠自己猜流程进行到哪一步了。

### 第二轮：Technical Interview

终于约上了第二轮 technical interview。第二轮问的问题和第一轮几乎一模一样，本来以为应该是想考察一些之前没有覆盖到的东西，结果还是同样的 high-level technical / behavioral questions。不过楼主自我感觉两轮都答得挺好，第二轮面试官当时的反应也挺 positive，所以面完之后就继续等消息。

## 面试结果反馈

然后又是漫长的等待。两周过去了，还是没有消息，忍不住又发了一封 follow-up email，想问一下目前的进展。

依旧没有任何回复。

又过了两周，也就是第二轮面试结束大概一个月之后，终于收到了拒信。但居然连拒信的邮件都没有写完整，最后的署名直接被 cut off 了。

看到这里真的有点哭笑不得……

## 面试体验

说实话，被拒本身完全可以接受。面试有不确定性，公司有自己的 hiring bar，candidate 和 team 不 match 都很正常。但整个过程真的让人很难理解。

楼主也面过不少其他公司，当然知道招聘流程可能会有各种变化，也理解 HR 可能很忙。但这种从头到尾几乎没有 communication、流程随时变化、最后连最基本的邮件都没写完整的体验，确实还是第一次遇到。整个过程让人感觉自己的时间完全没有被尊重。

move on了～
