# Oracle SDE实习面试面经

<InterviewDetail />

## 基本信息

- **岗位**：Software Development Engineer (SDE) Intern
- **地点**：Redwood Shores, CA
- **面试形式**：Recruiter 面试 + Coding + Hiring Manager 面试
- **候选人身份**：匿名
- **面试结果**：Accepted Offer
- **面试体验**：Positive
- **整体难度**：Easy

## 面试流程

### Recruiter Deep Dive

第一轮是 Recruiter 深聊，主要围绕候选人的个人背景、求职经历以及岗位匹配度展开。

### Coding Interview

随后进行了算法面试，一共两道 LeetCode Easy / Medium 难度的题目。

题目本身难度不高，关键在于注意题目给出的输入范围和约束条件。通过利用 constraints，可以找到更高效的最优解法。

具体题目包括：

- Two Sum（两数之和）
- 一道 Dynamic Programming（动态规划）题

### Hiring Manager Screen

Coding 结束后是 Hiring Manager 面试。

这一轮主要针对简历进行深入提问，包括候选人过往的项目、实习或相关经历，整体以 Resume Deep Dive 为主。

## 面试结果反馈

最终顺利通过面试，并接受了 Oracle 的 Offer。

## 面试总结

整体面试体验比较正面，算法题难度属于 Easy 到 Medium。

Coding 部分除了掌握常见 LeetCode 题型之外，也需要特别关注题目的 constraints，有时候输入范围本身就暗示了最优解法。

Hiring Manager 环节则建议提前熟悉简历中的每一段经历，并准备好深入解释项目细节。
