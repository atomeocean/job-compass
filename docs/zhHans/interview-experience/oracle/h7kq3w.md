# Oracle 健康组 全职 Onsite面试经验

<InterviewDetail />

## 面试详情

- **团队**：健康

onsite四轮，

### 第一轮：Task Tracker

第一轮给一些worker，给一些job，implement一个task tracker根据worker的capacity来分配job，不难，个人觉得主要focus在data model上面，

### 第二轮：Coding

第二轮coding，给一个数组和一些元素以及它们的最小出现频率，找最短连续窗口保证这些元素都出现这么多次，用sliding window，

### 第三轮：系统设计（Low Level Design）

第三轮系统设计比较措手不及，以为是和设计youtube设计uber一类的面试，但实际是low level design，要求设计一个交通控制系统，行人可以push button，灯会变，和lc上有一题的上下文比较类似但不是考察concurrency，到结束我也没意识到面试者要什么，最后说是expect我设计一个state machine，这轮应该挂了，

### 第四轮：Project Deep Dive

第四轮project deep dive，基本就是挖简历，过去的project，trade off之类的
