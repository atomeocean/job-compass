# 被折叠的面经

以下面经会被折叠，不出现在面经列表里：

1. 广告号或导流账号发布的面经，见[禁止引流和广告](/guide/rules/promotion)
2. 没有实质信息、内容重复或明显虚假的面经，见[禁止无意义内容](/guide/rules/low-quality)

AI 生成的面经不折叠，直接删除，见[禁止 AI 灌水内容](/guide/rules/no-ai-content)。
