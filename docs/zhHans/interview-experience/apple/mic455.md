# Apple Software Development Engineer 电面 + Virtual Onsite面试经验

<InterviewDetail />

## 面试详情

第一次面 Apple SDE，面的是 compute infra。

整体体验很差：电面三轮，virtual onsite 三轮。

Apple 是组招，每个组的面试风格不一样。我这个组是电话面试，一轮一轮地来，过了一轮才有下一轮。

### 电面

**第一轮**：OS、network 八股 + 多线程面试，具体是实现 queue 生产者消费者。印度🇮🇳女面试官，一个小时，真是强度拉满。最后连问十个八股问题，感觉是在不断挑战你。

**第二轮**：两道 easy-medium 的题 + 延伸到设计一个 log 分布式系统 让你统计log里的关键词。🇮🇳女manager面试官，感觉很严肃，不断挑战我。一个小时，强度拉满。体验最不好的一轮。感觉manager全程没有笑容，非常严肃😑。

**第三轮**：多线程面试，实现一个 cyclic barrier，要求非常底层。🇨🇳小哥，虽然强度不小，但是感觉到了关爱，非常感恩。

其实面完第二轮，印度 manager 就说不是很 match，因为我是做分布式数据平台/数据库的，她们是做 compute infra。不知道为什么还给我过了，邀请我参加 virtual onsite 三轮。

### Virtual Onsite

**第四轮**：又是多线程，面试官 ABC，实现 lock。嗯，你没听错，就是实现 lock，不能调现成的。然后又是基础知识考察。我以为 onsite 应该会是 system design + BQ，某些基础知识确实忘了，比如 TLS 的细节原理，这里没答好。

**第五轮**：面试官 abc，LeetCode 中等题，实现一个 event system，给你一个时间 window，大概就是用 deque + lock。最后又问了分布式系统的基础知识。

**第六轮**：🇮🇳面试官，面的是拓扑排序，做得很顺利，提前十分钟进入聊天环节。

## 面试体验

Apple 这个组的面试整体体验不是很好。HR 不会告诉你面试的 topic，哪怕是 onsite，HR 给我的面试 topic 都是错的。个人觉得这六轮里，第二轮和第四轮有些地方答得不好，挂算是意料之中。晚上收到挂的邮件了。毕竟现在市场 bar 很高，对容错率要求很低。六轮里唯一觉得暖心的还是第三轮的国人小哥，感觉应该给了我很高的评价，才让我走到 onsite。

体验不好的是，感觉面试官都是在不断挑战你，不是很友好，每一轮强度都很大。但是对system design和bq考察很少，大多集中在多线程和八股基础知识，这和传统的面试差别很大。然后🇮🇳manager 明显感觉对我兴趣不大，但是还让我继续 onsite。面完六轮，多多少少有些不厚道了。毕竟面了这么多轮，准备这么久，肯定有些难过。现在这市场，让我有点怀疑跳槽得准备和发挥到什么程度才能有offer呢？继续努力💪。

## 面试结果反馈

- **最终结果**：Fail
