# Apple SWE ICT3（IS&T）面试经验

<InterviewDetail />

## 基本信息

- **公司**：Apple
- **部门**：IS&T
- **岗位**：Software Engineer（SWE）
- **职级**：ICT3
- **面试流程**：1 轮 Technical Screen + 4 轮 Virtual Onsite
- **面试结果**：等待结果

## Technical Screen

一道 LeetCode Medium 难度的题目，外加一道 follow-up。

候选人完成了原题和追问，顺利进入 Virtual Onsite。原文未披露具体题目。

## Virtual Onsite

以下四轮不按实际面试顺序排列。

### Coding 1

两道 LeetCode Medium 难度的题目。

候选人完成了两题，并解释了时间复杂度和空间复杂度，自评表现良好。

### Coding 2

一道 LeetCode Medium 难度的题目，外加几道 follow-up。

候选人完成了原题和所有追问，自评表现良好。

### Hiring Manager

内容包括简历深挖、行为面试问题和一般交流。

候选人觉得交流顺利，并感觉 Hiring Manager 对自己的表现印象不错。原文未提供正式反馈。

### System Design

第一题是一道难度较高的分布式系统设计题。候选人一开始没有理解题意，紧张后也没能推进多少。候选人回忆，面试官几乎没有给提示，交流更像连续追问，较少有来回讨论。

接近结束时，面试官换了一道相对简单的题，候选人觉得自己也没有答好。原文未披露两道题的具体内容。

## 面试结果

截至发帖，距离最后一轮面试约一周。候选人已联系 recruiter 跟进，但尚未收到回复或正式结果。

候选人最担心的是 System Design 一轮的表现，想了解在 Coding 和 Hiring Manager 轮自评较好的情况下，仍有多大机会拿到 offer。
