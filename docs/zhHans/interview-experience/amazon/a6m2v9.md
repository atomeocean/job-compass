# Amazon SDE II 面试经验

<InterviewDetail />

## 面试基本信息

- 公司信息：[Amazon](https://www.amazon.jobs/)
- 面试时间：2026年9月

## 面试过程

### Online Assessment

第一部分是一道无人机环形配送问题。

给定相邻地点之间的移动时间，需要计算完成配送所需要的时间，可以利用 Prefix Sum 优化。

OA 还包含一个 AI Coding / Debugging 任务。候选人需要阅读现有 project 和 README，根据函数定义定位问题并修改代码。

### Phone Screen

Phone Screen 大约分成两部分：

- 30 分钟 Behavioral
- 30 分钟 Coding

Behavioral 涉及 missed deadline、主动发起的项目以及 high-impact project。

Coding 是车辆年检预约 scheduling 问题。给定营业时间、假期、appointment slot 长度以及等待登记的车辆数量，需要尽可能均匀地安排预约。

Follow-up 会改变每天可预约的时间范围。

### Virtual Onsite

第一轮由 Hiring Manager 进行。

Behavioral 主要围绕 AI Agent 项目、工作中的失误、主动改善流程、冲突以及如何面对 criticism 展开。

Coding 题与 Meeting Rooms / LeetCode 252 类似。

另一轮是 System Design，要求设计一个能够处理突发流量并保持低延迟的 notification microservice。

重点涉及 burst traffic 下的架构设计和系统扩展。

### 后续流程

候选人在完成部分 Virtual Onsite 后决定取消第二天剩余的面试，因此没有完成完整 onsite loop。

## 总结

这套流程同时覆盖了算法、debugging、项目 deep dive、Behavioral 和 System Design。

Amazon 的 Behavioral 与实际项目细节结合得比较紧，技术准备之外也需要提前整理具体的项目和 Leadership Principles 案例。
