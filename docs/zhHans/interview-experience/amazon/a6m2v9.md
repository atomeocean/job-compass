# Amazon SDE II Software Engineer Virtual Onsite面试经验

<InterviewDetail />

## 面试详情

HR 在 LinkedIn 上联系了我。我没回第一条消息，但之后两周每周都给我发一次消息。我当时也没什么事做，就想着不如面一下看看。

### 第一个岗位：OA

七月底，我做了第一个岗位的 OA，第二天就收到了 phone-screen 邀请。

其中一道题是无人机沿环线顺时针送包裹。题目给出相邻两个点之间的行驶时间，要求算出完成沿途所有配送的时间。我在小红书上看过原题，用了前缀和。第二道题是 AI coding，不过 AI 不太有用。我拿到的是一整个项目要 debug；看 README 里的函数定义就足够完成修复了。

两周后，也就是八月初，我还是没有收到任何消息。我问了 HR，被告知这个岗位已经招满了。

### 第二个岗位：Phone Screen

HR 给了我另外三个岗位让我选。我选了一个西雅图的团队，他们当天就安排了 phone screen。

一周后，我面了第二个岗位的 phone screen。SDE 面试官人很好，一直给我提示。有三十分钟的 behavioral questions 和三十分钟的 coding。她问了错过 deadline、我自己主动发起的项目、影响很大的项目，每个问题都有追问。感觉她主要是在收集信息。coding 题是她自己出的：年度车辆检测登记问题，要求每六个月登记一次。节假日不开放登记，只在上午 10 点到下午 4 点开放。每个时段一小时，每次登记占用一个时段。给定 n 辆等待登记的车，尽可能均匀地分配它们的登记。我一时不知所措，就一直和她交流，临场写了两个函数，一个处理时段，一个处理排期。追问是把每天的登记时间改成上午 11 点到下午 3 点。

### Virtual Onsite

我以为 phone screen 挂了，但第二天就收到了 virtual onsite 的时间调查，要求 24 小时内提交。我一收到就提交了。当天就确认了日期，是两周后。

他们到面试前一天才发来 virtual onsite 的详细安排。

我查了 LinkedIn。hiring manager 刚转了组，senior 面试官从 PM 转到了 SDE。另外两位面试官我找不到资料。

还有什么好说的呢？面就是了。我还能怎么办？

#### 第一轮：Hiring Manager

第一轮 virtual onsite 是和 hiring manager。他问了我简历上的 AI-agent 项目：是怎么做的，有多少人用，我和公司哪些部门合作过。他问了我最大的错误、有没有主动改进过公司流程、和别人的冲突，以及我怎么处理批评。到 behavioral questions 为止，感觉还可以。coding 很简单：正是 Meeting Rooms，[LeetCode 252](https://leetcode.com/problems/meeting-rooms/)。我先讲了双指针的思路，在起点处加 1，在终点处减 1。但我脑子一片空白，忘了需要返回最大值。他问："这样不会变成零吗？"我说我再看一下，但心里觉得我的思路应该是对的。我安静了一会儿，然后说应该在扫描过程中返回最大值。我 dry-run 了两个测试用例。他什么都没说，于是我写了代码并讲了复杂度。他突然说我肯定有多个屏幕。我愣住了，说："没有，我可以给你看我的房间。"他只是笑了笑，说时间到了。

到底是什么情况？？？

#### 第二轮

第二位面试官问了一些不寻常的 behavioral questions：我有没有学过新东西以及怎么应用到工作中，我在给公司带来最大收益的项目上做了什么，我为客户做过什么让他们非常满意。没有追问。然后直接进入 system design：设计一个接收通知的微服务，要处理突发的数据高峰并保持低延迟。我每问他一个问题，他都说由我决定。我画完图的时候，时间就到了。

等等，什么？？？？

我取消了第二天安排的面试。我不想继续下去了。这太荒谬了。这到底是什么意思？停下来思考就作弊？简直难以置信。他们看起来很难相处。就算我加入，也只会让自己痛苦不堪。
