# Amazon SDE 面试经验

## 面试基本信息

- 公司信息：[Amazon](https://www.amazon.jobs/)
- 面试时间：2026年4-6月

<InterviewDetail />

## 背景

候选人为硕士学历，在职跳槽期间参加了本次 Amazon 的招聘流程。

## 面试过程

### Online Assessment

本轮 OA 共分为四个部分：

**Part 1: DSA**

题目类似 LeetCode 上的 House Robber II。

**Part 2: AI Based Round**

基于代码仓库（Repository）的题目：

1. 给定一个代码仓库以及一个带有 guardrails 的 AI 模型。
2. 题目提供了一些处于失败状态的 test cases。
3. 需要在 AI 模型的辅助下，通过修改仓库代码来修复并跑通这些 test cases。

**Part 3: Work Simulation**

关于 Amazon 工作文化中决策能力的考察：

1. 涉及在 LLD（Low-Level Design）和 HLD（High-Level Design）设计场景下进行决策的题目。

**Part 4: Leadership Principles**

Amazon Leadership Principles（LP）相关的行为准则选择题。

## 结果反馈

最终结果为 Fail。
