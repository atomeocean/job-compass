# Amazon SDE New Grad技术电面经验

<InterviewDetail />

## 基本信息

- **面试日期**：近期
- **面试岗位**：Software Development Engineer（New Grad）
- **学历背景**：硕士
- **工作类型**：全职
- **投递方式**：内推
- **面试形式**：技术电面

## 面试详情

这一轮主要包含 Behavioral Questions 和 Coding 两部分。

### Behavioral Questions

主要围绕跨团队合作展开。

问题是：

> 分享一次依赖其他团队完成工作，但对方延期交付的经历。

后续进行了多轮 Follow Up，包括：

- 你是如何提前发现项目风险的？
- 你是如何与对方团队沟通并推动项目继续进行的？
- 有没有准备 Backup Plan？

整体比较符合 Amazon Leadership Principles，对项目推进能力和风险管理能力考察较多。

### Coding

#### 第一题

给定多个时间区间（Intervals），判断是否存在时间冲突。

解法比较直接：

- 按开始时间排序（Sort by Start Time）
- 比较相邻区间是否发生重叠

属于经典 Interval 问题。

#### Follow Up

如果需要同时安排所有任务，最少需要多少台机器（或会议室）？

可以使用：

- 扫描线（Sweep Line）
- 最小堆（Min Heap / Priority Queue）

计算任意时刻同时进行的任务数量，从而得到最少需要的机器数。

## 面试体验

整体难度中等。

BQ 部分会针对 STAR 故事不断追问细节，建议提前准备跨团队合作、项目延期、风险管理等相关经历。

Coding 是经典的 Interval 系列题目，Follow Up 考察从冲突检测扩展到资源分配问题，属于比较常见的面试套路。

## 面试结果反馈

- **最终结果**：Pass
