# 社区规则

Job Compass 只收录亲身经历或有出处的真实求职信息。下面的规则适用于所有投稿（面经、公司信息、招聘信息、文章）和评论区。

## 规则列表

| 规则 | 适用于 |
|---|---|
| [禁止 AI 灌水内容](/guide/rules/no-ai-content) | 投稿 |
| [禁止无意义内容](/guide/rules/low-quality) | 投稿 |
| [禁止引流和广告](/guide/rules/promotion) | 投稿、评论区 |
| [评论区规定](/guide/rules/comments) | 评论区 |

## 用词约定

投稿规则只用两种说法，后果不同：

| 说法 | 含义 |
|---|---|
| **禁止** | 不予正常收录，按各规则页的"违规处理"折叠、关闭或删除 |
| **不鼓励** | 审核时会要求修改，改好后照常收录 |

评论区的两档处理方式见[评论区规定](/guide/rules/comments)。

## 违规处理

- 审核人会在 PR 里回复违反了哪条规则、具体是哪部分内容，然后按下面的方式处理。
- 属于无意义内容或引流广告的面经，不论是否已经合并，都移入[被折叠的面经](/interview-experience/folded-entry/)：页面保留，但不出现在面经列表里。未合并的投稿由审核人移入后再合并。
- AI 生成的内容，以及其他栏目的违规内容：未合并的 PR 直接关闭，已收录的直接删除。
- 多次违规的账号会被屏蔽，之后的 PR 不再受理。

## 典型案例

每条规则页面的末尾列出几个典型案例，说明规则的边界在哪里，既有判定违规的，也有判定通过的。

- 案例只写做了什么、为什么这样判定，不写提交者或原帖作者的账号。
- 被折叠的面经留在站上，案例直接链接到它；已删除的违规内容存档在 [Atomeocean 回收站仓库](https://github.com/atomeocean/code-recycle-bin)，存档前会去掉作者信息、联系方式和广告链接。
- 每条规则最多保留 5 个案例，有更典型的案例时替换旧的。

认为某个案例判定有误，或者希望移除与你有关的案例，按下面的方式申诉即可。

## 举报与申诉

- **举报**：发现违规内容，可以在该页面下方评论，或者发邮件到 [customer@atomeocean.com](mailto:customer@atomeocean.com)，写明页面链接和原因。
- **申诉**：不同意判定，可以直接在 PR 里回复，或者在对应规则页下方评论。每一条申诉都会由管理员复核。

## 规则怎么修订

规则跟着真实遇到的问题修订：

1. 遇到规则没有覆盖的情况，先由管理员判定，并在 PR 里写明理由。
2. 同类问题反复出现时，修改规则正文，并在下方的修订记录里写明日期、改了什么、为什么改。
3. 删掉或改掉的规则不留在正文里，只记在修订记录中。

往规则页添加案例不算修订，不记入修订记录。对规则本身有意见，欢迎在本页下方评论。
