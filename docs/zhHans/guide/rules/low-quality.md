# 禁止无意义内容

## 规则

**禁止**提交以下内容：

- **没有实质信息**：读完学不到任何具体的东西，比如只有"面完了，感觉一般"。面经至少要包含可以复述的题目或流程细节。
- **与求职无关**：和找工作、面试、职业发展都没有关系。
- **重复**：和已收录的内容是同一篇，或者只是换了个说法。
- **明显虚假**：时间、流程或公司信息自相矛盾，或者与公开信息明显不符。
- **测试或占位**：空页面、只有模板没有内容的提交。

**不鼓励**内容单薄但有一定价值的投稿，比如只写了面试轮次、没有写题目。审核时会请你补充细节。

## 违规处理

- 未合并的 PR：直接关闭；属于"不鼓励"的，审核人会要求修改。
- 已收录的面经：移入[被折叠的面经](/interview-experience/folded-entry/)。其他栏目的内容直接删除。

## 典型案例

暂无。
