# 评论区规定

页面下方的评论区由 [Giscus](https://giscus.app/zh-CN) 提供，评论保存在 Job Compass 仓库的 [GitHub Discussions](https://github.com/atomeocean/job-compass/discussions) 里。发表评论需要登录 GitHub 账号，并遵守 GitHub 的服务条款。

## 规定

**禁止**：

- **引流和广告**：留联系方式、拉群、推广收费服务。标准和投稿相同，见[禁止引流和广告](/guide/rules/promotion)。
- **公开他人的个人信息**：真实姓名、联系方式、工作单位等非公开信息。
- **人身攻击**：针对人而不是针对内容的攻击、辱骂和骚扰。
- **用 AI 或脚本批量发评论**。

**不鼓励**：

- 和当前页面无关的讨论，请到 [GitHub Discussions](https://github.com/atomeocean/job-compass/discussions) 或 [Discord](https://discord.gg/qTHGss8GQH)。
- 只有"同问""mark"这类、没有实际内容的评论。

## 违规处理

| 说法 | 处理 |
|---|---|
| **禁止** | 评论删除；多次违规的账号会被屏蔽，不能再在评论区发言 |
| **不鼓励** | 评论被折叠隐藏，不删除 |

违规评论删除后不再保留，所以本页没有典型案例。

## 举报与申诉

举报违规评论，或者对处理结果有异议，可以发邮件到 [customer@atomeocean.com](mailto:customer@atomeocean.com)，写明页面链接和评论内容；也可以在[社区规则](/guide/rules/)页面下方评论。
