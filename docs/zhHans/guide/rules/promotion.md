# 禁止引流和广告

这条规则同时适用于投稿和[评论区](/guide/rules/comments)。

## 规则

**禁止**以下内容：

- **留联系方式或拉群**：微信号、QQ 号、群二维码，或者"私信我""加我拿资料"这类把读者引到私下渠道的话。
- **推广收费服务**：付费内推、代面、简历代写、求职中介、付费课程和题库。
- **只为推广外部网站**：核心内容只是商业网站、题库或课程的链接。
- **来源用于导流或推广**：转载的面经，原帖账号或来源平台主要在发广告、引流，或者推销自己的付费服务。

## 外链的边界

外链本身没有问题，要看它是在给读者提供信息，还是要把读者带走。

| 情况 | 判定 |
|---|---|
| 链接到原帖并注明出处（一亩三分地、小红书等） | ✓ 允许 |
| 链接到公司官网、职位页面、官方文档 | ✓ 允许 |
| 链接到公开、有实际内容的文章或视频，包括自己写的、自己拍的 | ✓ 允许 |
| 链接到付费课程、付费题库，或者付费才能看的页面 | ✗ 不允许 |
| 同一个账号的投稿或评论，反复只推同一个网站或频道 | ✗ 不允许 |

边界不清楚的情况由管理员判定。

## 转载的内容：看来源，不看转载人

转载的面经被判定违规，通常是因为原帖的来源账号在导流，而不是把它搬过来的贡献者做错了什么。这种情况算作来源违规，不算转载人违规。

## 违规处理

- 面经：不论是否已经合并，都移入[被折叠的面经](/interview-experience/folded-entry/)，页面保留，但不出现在面经列表里。未合并的投稿由审核人移入后再合并。
- 其他栏目：未合并的 PR 直接关闭，已收录的内容直接删除。
- 反复推广的账号会被屏蔽。
- 评论区里的引流和广告：按[评论区规定](/guide/rules/comments)处理。

## 典型案例

::: details ✗ 某书广告号发布的 Palantir 面经
- **判定**：2026 年 1 月，收录时直接折叠。
- **原因**：来源账号是广告号，帖子内容质量低，原帖链接已经无法打开。
- **处理**：页面保留在[被折叠的面经](/interview-experience/folded-entry/palantir)里，不出现在面经列表中。问题出在来源账号，不在转载的贡献者。
:::

::: details ✗ 商业备考平台 PracHub 收集改写的面经
- **判定**：2026 年 11 月，判定为来源违规。这个来源的两篇面经都移入折叠：一篇已经收录，一篇是新投稿。
- **原因**：PracHub 是付费备考站，从一亩三分地、Reddit 等网站收集面经后改写发布，没有具体作者，正文链接到平台自己的练习题。题目内容是真实的，但来源在为付费题库导流：内容有价值，也不能抵消来源的问题。
- **处理**：两篇保留在被折叠的面经里：[Amazon SDE II VO](/interview-experience/folded-entry/a6m2v9)、[LinkedIn SWE IC2](/interview-experience/folded-entry/l3n8q7)。找到原帖并改为引用原帖的，可以照常收录。
:::
