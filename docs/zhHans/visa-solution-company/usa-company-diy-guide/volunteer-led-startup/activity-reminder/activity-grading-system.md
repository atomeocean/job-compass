# 轻量员工活跃度

包含邮件通知，和discord通知。

以及微信通知

如果是活跃度不足，发friendly的。活跃度可以的就是常规反馈+再接再厉。活跃度不足就是紧急的通知。

## 分级制度

参考足球中的红黄牌设计

| 级别 | 轻量员工行为                 |
|----|------------------------|
| 普通 | 轻量员工活跃度合格，发普通的通知       |
| 黄牌 | 活跃度不足甚至为0，发friendly的通知 |
| 红牌 | 轻量员工活跃度不足，发urgent的通知   |
